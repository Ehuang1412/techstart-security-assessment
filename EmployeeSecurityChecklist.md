# TechStart Inc. — Employee Security Quick Reference

### 🔒 DAILY

- [ ] Lock your screen whenever you step away (Win+L / Ctrl+Cmd+Q)
- [ ] Verify the sender before clicking any link or attachment
- [ ] Use the company VPN when on public WiFi
- [ ]  Report suspicious emails immediately — don't forward, don't click
- [ ] Keep your laptop physically with you or secured in public
### 📅 WEEKLY

- [ ] Install any pending software/OS updates
- [ ] Review your account activity for anything unusual
- [ ] Empty your downloads folder of sensitive files
- [ ] Confirm no work files are on personal devices/accounts
### 🗓️ MONTHLY

- [ ] Update your password manager entries
- [ ] Complete any assigned security training modules
- [ ] Review who has access to your shared files/projects
- [ ] Check that MFA is enabled on all work accounts

### 🚨 EMERGENCY RESPONSE PROCEDURES

📧 If you receive a suspicious email:

1. Don't click anything
2. Report to security@techstart.com (or #security-alerts)
3. Delete it only after reporting
4. If you already clicked → tell IT immediately → change your password
   
💻 If your laptop is stolen:

1. Report to IT immediately (call + email)
2. IT will remote-wipe the device
3. Change passwords for all accounts accessed on the device
4. File a police report
5. Do not delay — every minute matters

🔓 If you suspect your account is compromised:

1. Change your password immediately
2. Enable/verify MFA
3. Report to IT
4. Review recent activity for unauthorized changes
5. Warn your team if it was a phishing attack

📉 If you discover a data breach:

1. Do not attempt to fix it yourself
2. Notify IT/management immediately
3. Preserve evidence (don't delete anything)
4. Follow instructions from the incident response team
5. Do not discuss publicly until cleared
